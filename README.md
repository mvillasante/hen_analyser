Statistical process control (X-R charts) for daily egg production in poultry flocks.

`huevolizer` computes eggs-per-hen from daily egg counts and flock censuses, fills gaps in time series data, and generates Shewhart control charts to monitor production stability. It includes a CLI tool and a Streamlit web app for data entry and visualization.
